# Code of Conduct

We want this repository to be welcoming, professional, and safe for customers, contributors, and learners.

## Expected behavior

- Be respectful, constructive, and solution-oriented.
- Assume good intent while giving specific technical feedback.
- Keep examples, issues, pull requests, and discussions suitable for a broad professional audience.
- Respect privacy, confidentiality, and responsible disclosure practices.

## Unacceptable behavior

- Harassment, discrimination, intimidation, or personal attacks.
- Publishing someone else's private information without permission.
- Sharing real credentials, sensitive customer details, or unsafe content in repository spaces.
- Disruptive behavior that prevents others from collaborating effectively.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, review comments, and other project interactions.

## Reporting

If you experience or observe unacceptable behavior, contact the maintainers through the support path documented in `SUPPORT.md`. Security-sensitive concerns should follow `SECURITY.md`.

Maintainers may edit, remove, or moderate content that violates this code of conduct.
