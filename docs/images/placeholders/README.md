## Replacement guidance

- Replace placeholders only with approved screenshots from a sanitized demo tenant.
- Keep file names stable so markdown links do not change.
- Preserve a professional aspect ratio and readable captions.
- Remove or obscure any identifiers, alerts, or text that could imply real customer data.
