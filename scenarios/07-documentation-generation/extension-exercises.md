# Extension exercises

## Suggested variations

1. Ask Copilot to create a one-page summary of the `gold` outputs consumed by the RetailSales semantic model.
2. Produce a data steward handoff note for the Silver quarantine table.
3. Generate a glossary of retail-purchases field names for workshop facilitators.
4. Add a release checklist for changes that affect `gold.Sales` or the RetailSales report.

## Production-hardening ideas

- Add manifest versioning so documentation regeneration can be tied to approved artifact changes.
- Validate published docs against the committed artifact names in CI.
- Extend the manifest with RACI ownership and incident-escalation details once approved.

## Facilitator review checklist

- [ ] The learner can explain why a manifest produces more reliable output than a free-form prompt.
- [ ] The learner can identify which content still requires human approval.
- [ ] The learner can tailor the same committed metadata for different audiences.
- [ ] The learner can distinguish draft documentation from approved customer-facing documentation.

## What work did Copilot eliminate?

Copilot removed repetitive drafting and helped the learner tailor the same technical facts for several stakeholder groups.
