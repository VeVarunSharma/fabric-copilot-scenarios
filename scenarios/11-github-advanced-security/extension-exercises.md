# Extension exercises

## Guided variations
1. Add a facilitator checklist for triaging a new CodeQL alert with severity and data-flow notes.
2. Add a workshop branch runbook for demonstrating how Dependabot and dependency review complement each other.
3. Create a tabletop incident drill for a leaked development token discovered by secret scanning.

## Persona-specific extensions
- **Security admin**: Map each GHAS feature to the required GitHub plan and enablement steps.
- **Engineering manager**: Add a pull request review checklist for Copilot-generated remediations.
- **Developer advocate**: Write a five-minute spoken demo track for the safe lab.

## Production-hardening exercises
- Add a repository policy matrix for code scanning, secret scanning, and push protection coverage.
- Define how remediation SLAs map to alert severity.
- Document how to store evidence from workshop findings without preserving risky branches.
