# Support

## What this repository supports

This repository is sample content for Microsoft Fabric, GitHub Copilot, and GitHub governance demonstrations. It is intended for:

- customer demos
- workshops and hackathons
- field enablement
- proof-of-concept learning and safe experimentation

## How to get help

- Use the issue forms for bugs, scenario requests, and scoped automation tasks.
- Use pull requests for specific fixes with validation results.
- For security issues, follow `SECURITY.md` instead of filing a public bug.

## Response expectations

Support is best effort unless your organization adds a separate operating model around this repository. Maintainers may prioritize:

1. security and governance issues
2. broken validation or workflow behavior
3. scenario correctness and customer-facing clarity
4. enhancement requests

## Out of support

This repository does not by itself provide:

- production deployment guarantees
- tenant-specific consulting or managed operations
- approval of live customer data usage
- storage of long-lived cloud credentials or secrets
